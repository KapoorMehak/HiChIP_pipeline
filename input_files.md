# Input files

## HiChIP FASTQ files
Paired-end sequencing data:
- `HiChIP_R1.fastq.gz`
- `HiChIP_R2.fastq.gz`

## ChIP-seq peak files
Consensus peaks in BED or narrowPeak format:
- `consensusChIP_peaks.bed`

## Reference genome
Mouse genome (mm10 / GRCm38):
- `GRCm38.p6.genome.fa`
- `GRCm38.p6.genome`
